# Диаграммы состояний

Наборы статусов собраны из пользовательских историй (CAB-1, CND-4, EMP-5, EMP-9), требований и BPMN. Единого описания переходов в исходных документах нет, поэтому диаграммы составлены по совокупности требований и помечены как производные.

## Отклик

```mermaid
stateDiagram-v2
    direction LR
    [*] --> Sent: Соискатель отправил отклик
    Sent: Отправлен
    Viewed: Просмотрен
    Invited: Приглашение
    Rejected: Отказ
    Reserve: В резерве
    NoAnswer: Без ответа
    Withdrawn: Отозван

    Sent --> Viewed: Работодатель открыл резюме (ФТ-8.2)
    Sent --> Withdrawn: Отзыв до рассмотрения (ФТ-5.9)
    Sent --> NoAnswer: 7 дней без смены статуса (ФТ-5.8)
    Viewed --> Invited: Приглашение (ФТ-8.3, ФТ-8.5)
    Viewed --> Rejected: Отказ (ФТ-8.3)
    Viewed --> Reserve: Резерв (ФТ-8.3)
    Viewed --> NoAnswer: 7 дней без решения
    NoAnswer --> Invited: Решение после пометки (CND-8)
    NoAnswer --> Rejected: Решение после пометки (CND-8)
    Invited --> [*]
    Rejected --> [*]
    Withdrawn --> [*]
```

Правила:
- Возврат к предыдущему статусу запрещён (CND-4).
- Каждая смена статуса записывается в историю с датой (ФТ-5.7, НФТ-20) и уведомляет соискателя.
- Чат открывается после статуса «Приглашение» (CAB-3, CND-7).
- Переходы из «В резерве» в исходных документах не описаны, см. [open-questions.md](open-questions.md).

## Вакансия

```mermaid
stateDiagram-v2
    direction LR
    [*] --> Draft: Работодатель создал вакансию
    Draft: Черновик
    Moderation: На модерации
    Published: Опубликована
    Rejected: Отклонена
    Paused: Приостановлена
    Removed: Снята с публикации
    Closed: Закрыта (архив)

    Draft --> Moderation: Отправка на модерацию (ФТ-7.3)
    Moderation --> Published: Одобрено (ФТ-9.2)
    Moderation --> Rejected: Отклонено с причиной (ФТ-9.2)
    Rejected --> Moderation: Исправлено, отправлено повторно (ФТ-7.4)
    Published --> Moderation: Изменены зарплата или требования (EMP-7)
    Published --> Paused: Приостановка (ФТ-7.5)
    Paused --> Published: Возобновление (ФТ-7.5)
    Published --> Removed: Истёк срок или решение по жалобе (ФТ-7.7, ФТ-9.4)
    Removed --> Published: Продление (ФТ-7.7)
    Published --> Closed: Закрытие (EMP-9)
    Paused --> Closed: Закрытие (EMP-9)
    Removed --> Closed
    Closed --> [*]
```

Правила:
- Модерация выполняется в течение 24 часов (EMP-5, ADM-1).
- Мелкие правки опубликованной вакансии не требуют повторной модерации (EMP-7).
- Отклики остаются доступны после закрытия вакансии; в избранном она помечается закрытой (EMP-9, VAC-7).
- Отклик на снятую или закрытую вакансию не принимается (ФТ-5.5).
