# Матрица трассировки

Связывает эпики пользовательских историй с функциональными требованиями, сценариями использования и элементами BPMN-процесса. Связь на уровне эпиков: в требованиях источником указан код эпика, а не конкретная история. В колонке требований в скобках число требований группы, затем требования других групп, ссылающиеся на этот эпик. Приоритеты: M, S, C по MoSCoW.
