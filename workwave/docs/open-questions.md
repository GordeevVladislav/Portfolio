# Открытые вопросы и допущения

## Решено

| Вопрос | Решение |
|---|---|
| Таймаут сессии | 15 минут (AUTH-8, НФТ-11, BPMN) |
| Срок для пометки «Без ответа» | 7 дней, без отдельного второго срока (CND-8, ФТ-5.8, BPMN) |
| Способ регистрации | Только по email (AUTH-1) |
| Подтверждение email | Ссылка из письма (ФТ-1.4, AUTH-3, CAB-5, BPMN) |
| Доступ без входа | Главная страница с поиском, категориями, «Как это работает», партнёрами, FAQ, регистрация и вход (ФТ-1.14) |

## Ошибки модели данных

Схема БД не соответствует требованиям (статусы откликов и вакансий, связь отклика с резюме, зарплатные ожидания, жалобы, уведомления и другое). Схема не менялась. Полный перечень: [database.md](database.md#известные-ошибки-модели).
