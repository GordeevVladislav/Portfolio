# Пользовательские истории

## Общие сведения

Документ содержит 68 пользовательских историй платформы поиска работы для четырёх ролей, сгруппированные в 9 эпиков. У каждой истории есть критерии приёмки и предварительный приоритет по MoSCoW.

**Роли**

| Роль          | Описание                                                      |
|---------------|---------------------------------------------------------------|
| Соискатель    | Ищет вакансии, ведёт резюме, откликается                      |
| Работодатель  | Публикует вакансии, обрабатывает отклики                      |
| Администратор | Модерирует вакансии, блокирует нарушителей, ведёт справочники |
| Система       | Автоматические действия: уведомления, проверки, таймеры       |
