# Глоссарий

| Термин | Значение |
|---|---|
| Соискатель | Пользователь, который ведёт резюме, ищет вакансии и откликается |
| Работодатель | Пользователь, который представляет компанию, публикует вакансии и обрабатывает отклики |
| Администратор | Сотрудник платформы: модерирует вакансии, разбирает жалобы, блокирует нарушителей, ведёт справочники |
| Система | Вспомогательный актор: проверки, письма, уведомления, статусы, таймеры |
| Резюме | Анкета соискателя: контакты, желаемая должность, опыт, образование, навыки |
| Вакансия | Публикация работодателя об открытой позиции |
| Карточка вакансии | Страница вакансии с полным описанием и действиями «Откликнуться», «В избранное» |
| Лента | Список опубликованных вакансий на главной странице, по умолчанию по дате публикации |
| Отклик | Заявка соискателя на вакансию: выбранное резюме и сопроводительное письмо |
| Статус отклика | Этап обработки отклика: Отправлен, Просмотрен, Приглашение, Отказ, В резерве, Без ответа, Отозван |
| Без ответа | Пометка отклика, если работодатель не менял статус 7 дней |
| Избранное | Список вакансий, сохранённых соискателем |
| Сохранённый поиск | Поисковый запрос с набором фильтров, который можно запускать повторно |
| Модерация | Проверка вакансии администратором перед публикацией |
| Справочник | Управляемый администратором список значений: регионы, сферы, статусы, причины отказа |
| Личный кабинет | Раздел соискателя: резюме, отклики, избранное, сохранённые поиски, уведомления, настройки |
| Эпик | Группа пользовательских историй одной темы |
| MoSCoW | Приоритизация: M (Must) обязательно, S (Should) желательно, C (Could) возможно |
| ФТ, НФТ | Функциональное и нефункциональное требование |
| UC | Use case, сценарий использования |
| BPMN | Нотация моделирования бизнес-процессов |
