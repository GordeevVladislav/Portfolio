Принципы изоляции данных (НФТ-8):
- Соискатель видит только свои отклики и резюме.
- Работодатель видит отклики только на вакансии своей компании.
- Контакты кандидата доступны только работодателю, которому тот откликнулся, или при открытой видимости резюме (ФТ-8.10).
