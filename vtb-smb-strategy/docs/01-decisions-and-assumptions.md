# 01. Принятые решения и реестр допущений

## Решения

| Вопрос | Решение |
|---|---|
| Группы клиентов | Обе: действующие (цель 5) и новые (цель 4), показатели раздельно |
| Определение продукта | Банковские продукты и небанковские сервисы вместе; единица счета: позиция каталога (торговый и интернет-эквайринг считаются одним продуктом) |
| «Используемый» продукт | Активность за последние 90 дней по порогам из `04-trajectory-implementation.md` |
| Сегмент | Торговля (28,9% базы), три подгруппы по задачам клиента |
| Территория | Москва и Московская область, масштабирование на Россию |
| Горизонт | 18 месяцев, альтернативный сценарий до 21 месяца |
| Охват | Основной сценарий 40% активных клиентов торговли, консервативный 25%, оптимистичный 60% |
| Старт | Действующие 1,96 (середина диапазона 1,7-2,2); новые 1,0 (только РКО) |

Цель 5 формулируется для сегмента программы (охваченные клиенты). Среднее по всей торговле показывается как справочное значение и как вклад в общую цель ВТБ.

Статус: **подтверждено** (пользователь согласился с рабочим значением), **рабочее** (принято без возражений, данных кейса нет), **проверить** (требует данных или ответа организаторов).

| Допущение | Значение | Статус |
|---|---|---|
| Деление торговли на подгруппы | 45% офлайн-розница, 25% опт и B2B, 30% маркетплейсы | рабочее |
| «Спящие» распределены по отраслям равномерно | 20% в каждой отрасли | рабочее |
| Стартовое проникновение действующих | 1,96 (банковских 1,95, небанковских 0,01) | рабочее |
| Корзина действующих (цель) | банковские 3,40, небанковские 1,60, итого 5,00 | рабочее |
| Корзина новых через 12 месяцев | 4,00 | рабочее |
| Охват и волны | 5% (месяц 3), +15% (6), +10% (9), +10% (12) | рабочее |
| Выход когорты на цель | 6 месяцев (действующие), 12 месяцев (новые); консервативно 9 | проверить |
| Доля привлечения новых клиентов | 10% (сценарии 5% и 15%) | проверить |

| Эквайринг | оборот 1,5-3 млн руб. в год на клиента, комиссия 1,0-1,2% (15-36 тыс. руб. в год) | проверить |

| Реактивация «спящих» | цель 2 используемых продукта, 25% за 90 дней | рабочее |
| Масштаб на Россию | коэффициент 6 (520 тыс. / 86,7 тыс.) при тех же ценах и оборотах | проверить |

## Что исключено из расчета эффекта

- Кредиты, депозиты, ВЭД и гарантии: их доход процентный или маржинальный, а не прямой платеж клиента. Исключение консервативное.
- Бесплатная база (бухгалтерия, ЭДО) выручки не дает по правилам Приложения 3; затраты банка на нее кейс считать не требует.
- Реактивация «спящих» и сам доход от привлечения новых клиентов (РКО).
- Деление торговли на массовый и средний сегменты: в кейсе нет долей, расчет ведется по торговле целиком.
