# Интернет-магазин мерча: пакет аналитических артефактов

Учебно-портфолио кейс бизнес/системного аналитика. Заказчик (владелец бренда одежды и аксессуаров) прислал голосовое сообщение и 4 письма с противоречивыми требованиями. Задача: превратить хаос в пакет артефактов для команды разработки.

**Итог в одну строку:** MVP интернет-магазина мерча с самовывозом из магазина, оплатой только картой онлайн, бронированием товара на 15 минут и подарочными наклейками при заказе от 2 000 ₽.
