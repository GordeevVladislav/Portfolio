# Студенческие стартап-проекты: аналитика и продуктовая работа

**Роль:** аналитик / product manager · **Период:** март 2024 – авг. 2025 · **Организация:** ВГТУ

## Коротко
- Подготовил **21 заявку** на грант (программа «Студенческий стартап», Фонд содействия инновациям).
- Привлечено **6 млн ₽** (6 грантов по 1 млн ₽).
- Каждый проект обосновывал анализом рынка **TAM / SAM / SOM**, анализом конкурентов, бизнес-моделью и планом MVP.
- Для каждого проекта делал презентацию: проблема → решение → рынок → конкуренты → монетизация → план → выводы.

## Что входит в заявку (мой стандартный пакет)
| Блок | Что делал |
|---|---|
| Проблема и ЦА | 20–30 проблемных интервью на проект, сегменты, боли |
| Рынок | Расчёт PAM/TAM/SAM/SOM с источниками и допущениями |
| Конкуренты | Матрица сравнения 4–6 игроков, плюсы/минусы, УТП |
| Бизнес-модель | Тарифы, юнит-экономика, каналы дохода |
| План MVP | Календарный план на 12 мес. и бюджет 1 млн ₽ по этапам |
| Презентация | 10–14 слайдов с выводами |
